## 📌 Sobre o Projeto
Este repositório contém a solução completa para a **Atividade IV de Banco de Dados Relacional**. O projeto foi concebido para o domínio de uma Clínica Veterinária e Petshop (**PetVida**), contemplando desde a modelagem lógica, normalização (1FN até 4FN), povoamento e consultas SQL avançadas até a publicação do front-end na nuvem.
